# Atelier Finance

Tableau de bord financier en React et Vite, conçu comme un prototype portfolio responsive.

## Démarrage

Installez les dépendances avec npm install, puis lancez npm run dev.

## Fonctions

- Vue d’ensemble du solde, des revenus et des dépenses
- Historique des transactions avec ajout, modification, suppression et recherche
- Budgets par catégorie et graphique sur 30 jours, 6 mois ou 12 mois
- Export des transactions au format CSV
- Thème clair ou sombre
- Données enregistrées localement dans le navigateur

Les opérations affichées au premier lancement sont des exemples de démonstration.
